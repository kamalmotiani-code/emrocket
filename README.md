# EMRocket launcher

Installable home-screen launcher for **EMRocket**, EMotorad's sales check-in app.

- Opened in a browser: shows an **Install EMRocket** button (Android/Chrome) or Add to Home Screen steps (iPhone).
- Opened from the installed icon: goes straight to the EMRocket app (a Google Apps Script web app that
  requires an EMotorad Google account).

This repository holds only the launcher page, app manifest and icons. No data is stored here.
